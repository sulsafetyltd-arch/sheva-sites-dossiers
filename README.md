# סול בטיחות — תיקי שטח ודוחות ליקויים

אפליקציית ווב מובייל (עברית, RTL) לניהול תיקי שטח כיבוי אש ולהפקת **דוחות ליקויי בטיחות מהשטח** עם צילום וזיהוי AI.

## דוחות ליקויים AI

נתיב: `/safety`

1. בחירת תחום: בנייה / מפעל / משרדים / מחסן / ציבורי / **תשתיות** / כללי  
2. צילום בשטח (מצלמה אחורית) או העלאה מהגלריה  
3. זיהוי ליקויים באמצעות AI  
4. אישור / דחייה / סימון תוקן  
5. הפקת דוח להדפסה ו-PDF  

### דיוק זיהוי
- **Vision API**: מודל `gpt-4o`, `detail: high`, temperature נמוך, קטלוג ליקויים בפרומפט, סינון לפי confidence  
- **מצב מקומי**: ניתוח מאפייני תמונה (כהות/חפירה, אפור/אספלט, כתום/PPE, צפיפות קצוות) + מילות מפתח מהערות  

### הפעלת Vision API

1. פרסום הפונקציה `supabase/functions/analyze-safety-photo`  
2. הגדרת סוד `OPENAI_API_KEY` בפרויקט Supabase  
3. הרצת המיגרציה `supabase/migrations/20260715070000_safety_inspections.sql` (אופציונלי לסנכרון ענן)

בלי מפתח API האפליקציה עובדת במצב AI מקומי משופר.
